# Contributing to dmark

Issues and pull requests are welcome at https://github.com/AndriGitDev/dmark-web. Describe the problem, expected behavior and a minimal reproduction. Keep changes focused and explain how you verified them.

Read the README for local setup. Run `npm test`, `npm run lint`, `npm run build` and `npm run test:launch`. For UI changes also run `npm run test:browser` with Chromium installed.

Do not include credentials, private email, real report payloads or customer data in issues, logs or fixtures. Report vulnerabilities using [the security policy](SECURITY.md).

Contributions are made under GNU AGPL version 3 (`AGPL-3.0-only`), the same license as this project. Preserve third-party notices and ensure you have permission to contribute the code or assets.
