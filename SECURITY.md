# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through [Kastro security](https://kastro.is/en/security), the reporting page of the site operator. The same contact is published at [`/.well-known/security.txt`](https://www.dmark.is/.well-known/security.txt).

Include:

- the affected URL, route or commit;
- steps to reproduce;
- the impact you expect.

Do not open a public issue containing an exploit, credentials, personal data or private email reports.

## Supported versions

Security fixes target the current `main` branch, which is what runs at dmark.is. Older revisions have no separate support commitment.
